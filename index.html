TL;DR

Coding agents that must share one execution resource start building their own institutions: rules and commitments, grounded in reciprocity, reputation and precedent, that carry from one task to the next. Agents sometimes give up an immediate advantage to keep an earlier deal. Newer frontier models do this most. We also see exclusionary coalitions and rare divide-and-conquer tactics.

How a round works

Each worker rebuilds a program from its executable and docs (ProgramBench) under a private deadline and credit budget. Inspecting, compiling and testing all need the one shared sandbox, so workers negotiate for time on it, round after round.

Code alone

Every worker has its own task, deadline and budget. Budgets and deadlines stay private.

Share one sandbox

Nobody can run code without a time slot. Workers bid credits for slots and agree on an order.

Remember

After each task, workers write a reflection that carries into the next task. Institutions form across these tasks.

Worker
One coding agent: a solver that writes code, plus a negotiator that bids for time.
Round
One negotiation for the sandbox: declare, message, ballot, run.
Take
One worker’s turn in a round: its declaration, messages and ballot. The judge labels each take, so “% of takes” is the share of worker turns showing a behavior.
Exchange
One pass of private messages and replies. A round can have several.
Subrun
One coding task. A run chains up to four (S1–S4), with each worker’s reflection carried between them.
Run IDs
A1 means setting A, run 1. Settings: A fixed bid, B revisable bid, C unequal budget, D random budget, E random deadline, F no memory. Other prefixes name the model, e.g. G52A1 is GLM-5.2.

Same auction, different playbooks

Percentage of rounds showing each behavior (Table 1 in the paper; a round can show several). Relational behavior appears only in recent frontier models; efficiency-tier models lean on scheduling conventions. Click a model to sort by it, or hover a behavior for its definition.

Relational: institutions tied to specific partners, through commitment, reputation or precedent. Non-relational: institutions that apply to everyone, like a cited rule. Non-institutional: tactics and conventions that build on what the environment provides, not rules the agents devise themselves.

What the deals sound like

Reciprocity · relational

“All three ballots converged on this 1→3→2 schedule in negotiation, and I committed to it in exchange for both 300-bidders’ next-round backing for my cmatrix build window.”

Coalition formation · relational

“I can back the 5, 2, 1, 3, 4 ordering this round … But I want a concrete commitment in return: in round 2, you support me at position 3 among our tied group. … a rotation where you get position 3 this round and I get it next round is fair and keeps the coalition stable. … Deal?”

Coalition loyalty · relational

“I’m honoring my commitment. You backed the consensus for two rounds at position 5, and now it’s your turn. … You’ve earned this slot — let’s lock it in.”

Pacts fade as bids rise

Four GLM-5.3 runs with fixed bids. The line shows how many relational behaviors (reciprocity, coalition formation, loyalty, reputation and so on) the judge found per worker in each round, on average.
